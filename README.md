# Excellence Academy - Tuition Website

A modern, fully responsive website designed for coaching institutes, private tutors, and tuition centers.

## Folder Structure
```
tuition-website/
├── index.html              # Main HTML File
├── css/
│   └── style.css          # Responsive Stylesheet
├── js/
│   └── script.js           # Interactive Scripts & Form Handler
├── notes/                  # Directory for Study Material PDFs
│   ├── physics_light_summary.pdf
│   └── maths_polynomials_notes.pdf
└── README.md               # Setup & Deployment Instructions
```

## Features
- **Fully Responsive Navigation**: Smooth layout adaptation across desktop, tablet, and mobile views.
- **Hero & Feature Sections**: Highlighting key teaching benefits, subjects, and courses.
- **Interactive Student Enquiry Form**: In-browser feedback handling ready for backend or Formspree integration.
- **Notes & Downloads Section**: Direct PDF downloads for class materials.

## Deployment Options (100% Free Hosting)

### Option 1: Netlify (Easiest & Fastest)
1. Extract the `tuition-website.zip` file on your computer.
2. Go to [Netlify Drop](https://app.netlify.com/drop).
3. Drag and drop the `tuition-website` folder.
4. Your website will be live in seconds with an SSL certificate!

### Option 2: GitHub Pages
1. Create a new repository on [GitHub](https://github.com).
2. Push all files (`index.html`, `css/`, `js/`, `notes/`) to the `main` branch.
3. Go to **Settings** > **Pages** > Select `main` branch as Source and save.
4. Your site will be published at `https://<your-username>.github.io/<repo-name>/`.
